# Exclusive - E-Commerce Template

This is a frontend E-Commerce website template built using HTML, CSS, and Vanilla JavaScript. This project was developed as part of **Assignment Day 1** for the **MaiATech Internship**.

## Features
- **Responsive Design**: Optimized for desktop, tablet, and mobile viewing.
- **Modern UI/UX**: Clean and professional interface.
- **Multiple Pages**: Includes Home, About, Contact, Product Details, Cart, Checkout, Login, Sign Up, and 404 Error pages.
- **Vanilla Web Technologies**: Built without heavy frameworks, utilizing pure HTML, CSS, and JS.

## Tech Stack
- **HTML5**: For semantic page structure.
- **CSS3**: For styling, responsive layouts (Flexbox/Grid), and animations.
- **Vanilla JavaScript**: For interactive components and DOM manipulation.

## Getting Started
To view the project locally:
1. Clone this repository:
   ```bash
   git clone https://github.com/thinhbui-303/Assignment_01_Internship.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Assignment_01_Internship
   ```
3. Open `pages/index.html` in your web browser.
